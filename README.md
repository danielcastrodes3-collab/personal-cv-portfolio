# Daniel Castrodes — Personal CV Portfolio

A responsive personal Curriculum Vitae and professional portfolio website created for academic and career use.

## About

This website presents my personal profile, education, technical and professional skills, projects, internship experience, certificates, and contact information. It is designed as a foundation for future internship, employment, freelance, and professional opportunities.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
- Vercel (deployment)

## Main Features

- Modern dark purple/blue portfolio design
- Responsive desktop, tablet, and mobile layouts
- Smooth scrolling
- Scroll reveal animations
- Animated hero title
- Interactive cards and hover effects
- Mobile navigation
- Project portfolio
- Certificate gallery with modal preview
- Social and contact links
